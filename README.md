# RoomCraft 3D · 室内装修设计演示

在浏览器里画户型、摆橱柜衣柜灯具窗帘、实时换尺寸和材质、出效果图和 360° 全景，并自动生成报价单 PDF。

A browser-based interior configurator: draw a floor plan, place modular cabinets, wardrobes, lights and curtains, change sizes and finishes live, export renders and 360° panoramas, and generate a quotation PDF.

**在线演示：** https://jl0711.github.io/roomcraft-3d/

**代码：** https://github.com/JL0711/roomcraft-3d

## 功能

| 功能 | 做法 |
|---|---|
| 户型导入、3D 空间 | 2D 户型编辑器：拖角点改形状、加减角点、输入精确墙长；可以导入户型图片做底图描绘，也能导入/导出户型 JSON。任意多边形（包括 L 形）自动生成墙体、地面和天花，墙角做斜接。 |
| 模块化选配 | 地柜、吊柜、高柜、衣柜、吊灯、吸顶灯、窗帘、窗户。拖动时自动贴墙、和相邻柜子对齐，离墙远的地柜可以独立摆放（岛台）。重叠会标红提示。 |
| 实时换尺寸、材质、颜色、款式 | 宽高深、离地高度；门数、柜门或抽屉；平板、框式、竖纹门板；7 种饰面加自定义颜色；拉手和五金颜色；台面；灯罩、色温、开关；窗帘面料、拉开程度、纱帘。 |
| 高清效果和 360° 全景 | PBR 材质、阴影、环境光反射，白天和夜晚两种光线。“高清效果图”按当前视角输出约 4K 图片；“360° 漫游”可以站在房间里环视；“导出 360° 全景图”输出标准 2:1 等距柱状投影图片。 |
| 自动报价、导出 PDF | 每个模块按尺寸、饰面、款式、五金实时计价，台面按材质合并，地面和墙面按面积计价，加安装费和 9% GST。PDF 带效果图、客户信息、明细和合计，中文排版正常。 |
| AI 辅助设计（预留） | “一键布置”按房间类型和墙长自动摆放整套模块。现在是规则算法，输入输出都是普通 JSON，以后可以换成大模型生成。 |
| 其他 | 撤销/重做、复制、快捷键、方案自动保存到浏览器、方案文件保存和打开、导出 GLB（glTF 2.0）模型、中英文界面切换。 |

## 技术栈

React 19 · TypeScript · Three.js r187 · React Three Fiber · drei · zustand · jsPDF · Vite

所有贴图（木纹、地板、瓷砖、水磨石、大理石、石英石、花岗岩、竖纹法线贴图）都在运行时用 canvas 生成，不依赖任何图片素材。

## 实现要点

- **墙体：** 根据户型多边形算出每面墙的内侧法线，外角用两条偏移线求交点做斜接，凹角（L 形）也能正确闭合。
- **剖切视角：** 每帧判断相机在每面墙的哪一侧，挡住视线的墙自动淡出，只留墙顶轮廓，从任何角度都能看到室内。
- **吸附：** 拖动时把指针投到模块中心高度的水平面上，再投影到最近的墙；同一面墙上的模块按边缘对齐，吊柜会和下面的地柜对齐，窗帘会和窗户居中。
- **真实比例贴图：** 盒子几何体的 UV 按米重写，同一种木纹在大柜子和小抽屉上纹理大小一致。
- **360° 全景：** 用立方体相机渲染 6 个方向，再用全屏着色器展开成等距柱状投影；渲染目标不经过色调映射，所以在着色器里手动做 ACES 色调映射和 sRGB 转换。
- **报价单 PDF：** 先在 A4 尺寸的 canvas 上排版再放进 PDF，中文不需要嵌入字体，自动分页。

## 本地运行

```bash
npm install
npm run dev
```

```bash
npm run build
```

`dist/` 是纯静态文件，可以直接放到 GitHub Pages、Vercel、Netlify 或任何静态服务器。

## 目录

```
src/
  scene/Viewport.tsx   3D 场景、灯光、相机、拖动吸附
  scene/Room.tsx       墙体、地面、天花和剖切淡出
  scene/models.tsx     柜体、门板、拉手、灯具、窗帘、窗户的参数化模型
  ui/PlanEditor.tsx    2D 户型编辑器
  ui/Inspector.tsx     属性面板
  layout.ts            户型模板和一键布置
  placement.ts         贴墙、对齐、碰撞检测
  quote.ts / pdf.ts    报价计算和 PDF
  capture.ts           高清图、360° 全景、GLB 导出
  textures.ts          程序生成贴图
```
